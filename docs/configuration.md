# Configuration

All gateway runtime settings use environment variables. Bun reads `.env` from the working directory; exported variables win. Docker accepts `--env-file .env` and `-e NAME=value`. Compose forwards every setting below and accepts `.env` values or exported overrides. Change a running container's configuration with `docker compose up -d --force-recreate`.

```sh
# Local: override values from .env.
PORT=4321 MAX_RETRIES=3 bun start

# Compose: change both the internal port and the host port.
PORT=4321 GATEWAY_PUBLISHED_PORT=8080 MAX_RETRIES=3 docker compose up -d

# Direct Docker: keep the process reachable through the container interface.
docker run --rm --env-file .env -e HOST=0.0.0.0 -e PORT=4321 \
  -p 127.0.0.1:8080:4321 -v copilot-gateway-data:/data \
  ghcr.io/jn-aman/copilot-gateway:latest
```

The server and Compose host port bind to all interfaces by default. To restrict local access, set `HOST=127.0.0.1` for Bun or `GATEWAY_BIND_ADDRESS=127.0.0.1` for Compose. Keep Docker `HOST=0.0.0.0` so published ports can reach the process. Clients use `localhost` or the machine IP, rather than `0.0.0.0`.

Invalid settings fail at startup with field names, without printing their values. Boolean switches accept the values shown below. Limits remain bounded; credential protections and the rule against replaying ambiguous generations always apply.

## Server and requests

| Variable                      | Default                       | Meaning                                                                               |
| ----------------------------- | ----------------------------- | ------------------------------------------------------------------------------------- |
| `GATEWAY_API_KEY`             | required / generated by setup | Client authentication; 16–512 characters                                              |
| `HOST`                        | `0.0.0.0`                     | Process bind address; Docker needs a container-facing interface                       |
| `PORT`                        | `4141`                        | Process port; Compose updates its target port automatically                           |
| `REQUEST_TIMEOUT_MS`          | `300000`                      | Total request deadline, including streaming                                           |
| `SERVER_IDLE_TIMEOUT_SECONDS` | `30`                          | Idle connection/body reception timeout; application deadlines govern inference        |
| `SHUTDOWN_GRACE_MS`           | `10000`                       | Time to drain existing work before aborting                                           |
| `MAX_CONCURRENT_REQUESTS`     | `8`                           | Active upstream operations                                                            |
| `MIN_REQUEST_INTERVAL_MS`     | `0`                           | Local request pacing                                                                  |
| `MAX_BODY_BYTES`              | `4194304`                     | Incoming JSON limit                                                                   |
| `MAX_RESPONSE_BYTES`          | `16777216`                    | Nonstream inference response limit                                                    |
| `MAX_CATALOG_BYTES`           | `8388608`                     | Model discovery response limit                                                        |
| `MAX_SSE_EVENT_BYTES`         | `1048576`                     | Maximum individual streamed event                                                     |
| `MAX_TOOL_BUFFER_BYTES`       | `4194304`                     | Accumulated fallback tool fragments                                                   |
| `MAX_PARALLEL_TOOLS`          | `128`                         | Fallback tool count                                                                   |
| `LOG_REQUESTS`                | `true`                        | Request metadata logging; `false` disables it                                         |
| `MAX_RETRIES`                 | `2`                           | Inference transport retry budget; generations only retry explicit rate-limit refusals |
| `MAX_RETRY_DELAY_MS`          | `10000`                       | Largest retry wait accepted by the gateway                                            |

## Discovery and upstream

| Variable                    | Default              | Meaning                                                          |
| --------------------------- | -------------------- | ---------------------------------------------------------------- |
| `ACCOUNT_TYPE`              | `individual`         | `individual`, `business`, or `enterprise` fallback routing       |
| `COPILOT_API_URL`           | automatic            | Explicit HTTPS inference origin, overriding discovered routing   |
| `COPILOT_API_VERSION`       | `2026-06-01`         | Upstream API version header                                      |
| `EDITOR_VERSION`            | `1.115.0`            | Editor version used for inference and GitHub credential requests |
| `PLUGIN_VERSION`            | `0.44.0`             | Copilot plugin version headers                                   |
| `COPILOT_INTEGRATION_ID`    | `vscode-chat`        | Integration header                                               |
| `COPILOT_INTENT`            | `conversation-panel` | Intent header                                                    |
| `COPILOT_INTERACTION_TYPE`  | `conversation-panel` | Interaction type header                                          |
| `MODEL_ALIASES`             | `{}`                 | JSON object mapping client names to exact catalog IDs            |
| `MODEL_CACHE_TTL_MS`        | `60000`              | Catalog cache lifetime                                           |
| `MODEL_REFRESH_TIMEOUT_MS`  | `15000`              | Shared catalog refresh deadline                                  |
| `MODEL_REFRESH_COOLDOWN_MS` | `5000`               | Minimum interval between forced unknown-model refreshes          |
| `STARTUP_TIMEOUT_MS`        | `20000`              | Initial discovery / launcher selection deadline                  |

Endpoint overrides must be HTTPS origins without paths, query strings, or credentials. These destinations receive account credentials: configure only origins you trust. Automatic endpoint discovery remains restricted to trusted `githubcopilot.com` hosts. Redirects are refused.

## Login and credentials

| Variable                    | Default                          | Meaning                                                                                 |
| --------------------------- | -------------------------------- | --------------------------------------------------------------------------------------- |
| `GITHUB_TOKEN`              | unset                            | Optional runtime OAuth credential; device login avoids this variable. PATs are rejected |
| `GITHUB_TOKEN_FILE`         | automatic                        | Credential file override                                                                |
| `XDG_DATA_HOME`             | `~/.local/share`; Docker `/data` | Credential directory; file is `copilot-gateway/github-token` underneath                 |
| `GITHUB_API_URL`            | `https://api.github.com`         | GitHub token exchange / usage origin                                                    |
| `GITHUB_LOGIN_URL`          | `https://github.com`             | Device authorization origin                                                             |
| `GITHUB_OAUTH_CLIENT_ID`    | `Iv1.b507a08c87ecfe98`           | Device-flow OAuth application                                                           |
| `GITHUB_OAUTH_SCOPE`        | `read:user`                      | Requested OAuth scope; custom applications must support Copilot access                  |
| `GITHUB_REQUEST_TIMEOUT_MS` | `15000`                          | GitHub request deadline                                                                 |
| `GITHUB_MAX_RETRIES`        | `2`                              | Safe GitHub read retry budget                                                           |
| `GITHUB_MAX_RETRY_DELAY_MS` | `5000`                           | Largest GitHub retry wait                                                               |
| `TOKEN_REFRESH_COOLDOWN_MS` | `5000`                           | Cooldown after token refresh failure                                                    |
| `TOKEN_REFRESH_SKEW_MS`     | `60000`                          | Refresh ahead of expiry, capped at half the token lifetime                              |

`auth` does not require `GATEWAY_API_KEY`. Credentials persist with owner-only permissions. Keep them out of Git and images. Custom mounted paths must be writable for login and readable by container UID 1000.

## Optional Claude Code launcher

These settings affect `bun run claude`. Any compatible client can connect directly to the server.

| Variable                                         | Default           | Meaning                                            |
| ------------------------------------------------ | ----------------- | -------------------------------------------------- |
| `CLAUDE_BIN`                                     | `claude`          | Executable name or absolute path                   |
| `CLAUDE_PROJECT`                                 | current directory | Project directory; `--project` takes precedence    |
| `CLAUDE_MODEL`                                   | discovered        | Primary native Claude model ID or configured alias |
| `CLAUDE_FAST_MODEL`                              | discovered        | Fast model ID or alias                             |
| `CLAUDE_OPUS_MODEL`                              | discovered        | Opus model ID or alias                             |
| `CLAUDE_CODE_ENABLE_GATEWAY_MODEL_DISCOVERY`     | `1`               | Client discovery switch, `0` or `1`                |
| `CLAUDE_CODE_GATEWAY_MODEL_DISCOVERY_TIMEOUT_MS` | `15000`           | Client discovery deadline                          |
| `CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC`       | `1`               | Client traffic switch, `0` or `1`                  |

Model overrides must resolve to policy-allowed native Claude models. The launcher configures the child process; other Claude CLI arguments and MCP settings are forwarded normally. The Docker image contains the gateway; run Claude Code on your client machine.

## Docker Compose deployment

| Variable                    | Default                                  | Meaning                                                     |
| --------------------------- | ---------------------------------------- | ----------------------------------------------------------- |
| `GATEWAY_IMAGE`             | `ghcr.io/jn-aman/copilot-gateway:latest` | Image/tag/digest; pin a version for upgrades                |
| `GATEWAY_BIND_ADDRESS`      | `0.0.0.0`                                | Host interface for the published port                       |
| `GATEWAY_PUBLISHED_PORT`    | `4141`                                   | Host port, independent of process `PORT`                    |
| `GATEWAY_CREDENTIAL_VOLUME` | `copilot-gateway-credentials`            | Persistent named volume                                     |
| `GATEWAY_ENV_FILE`          | `.env`                                   | Container environment file                                  |
| `GATEWAY_RESTART_POLICY`    | `unless-stopped`                         | Docker restart policy                                       |
| `GATEWAY_STOP_GRACE_PERIOD` | `15s`                                    | Docker stop deadline; keep greater than `SHUTDOWN_GRACE_MS` |

For a custom env file, pass `docker compose --env-file /path/config.env ...` so Compose interpolation and the container agree. Set `GATEWAY_ENV_FILE=/path/config.env` there too. Defaults use `/data`; if changing `XDG_DATA_HOME`, ensure the mounted directory belongs to UID 1000. Direct Docker users control volume mounts and host port mapping with Docker flags.
